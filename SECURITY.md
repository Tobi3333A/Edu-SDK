# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main` and to the current
published versions of:

- `edu-sdk`
- `@edu-sdk/react`

Older releases may not receive patches.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Prefer reporting through
[GitHub Security Advisories](https://github.com/Tobi3333A/edu-sdk/security/advisories/new)
for this repository.

Include as much detail as you can:

- Description of the issue
- Steps to reproduce
- Affected package(s) and versions
- Impact assessment, if known

We will acknowledge the report when possible and work on a fix. Please give us
reasonable time to release a patch before any public disclosure.
