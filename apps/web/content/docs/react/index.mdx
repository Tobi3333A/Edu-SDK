title: React
description: UI components in the @edu-sdk/react package.
---

`@edu-sdk/react` renders data produced by `edu-sdk`.

| Component | Data |
| --- | --- |
| [`<Flashcards />`](/docs/react/flashcards) | [`createFlashcards()`](/docs/core/create-flashcards) |
| [`<Quiz />`](/docs/react/quiz) | [`createQuiz()`](/docs/core/create-quiz) |
| [`<StudyGuide />`](/docs/react/study-guide) | [`createStudyGuide()`](/docs/core/create-study-guide) |
| [`<PracticeProblems />`](/docs/react/practice-problems) | [`createPracticeProblems()`](/docs/core/create-practice-problems) |

There is no component for [`createNote()`](/docs/core/create-note).

Styling has three levels. See [Styling](/docs/react/styling):

1. Import `@edu-sdk/react/styles.css` for the defaults.
2. Pass `className` / `classNames` to override parts of a component.
3. Set CSS variables (for example `--edu-quiz-background`) to theme the defaults.

See [Quick Start](/docs/getting-started/quick-start) for `<Quiz />`.
